MTBS Assessment Type Comparison

Assessment Type Timing / Method Ecosystem Type Severity Characteristics Implications for Analysis
Initial Assessment Defined after fire termination to assess consumption and first-order mortality (Kolden 2012) Grasslands and shrublands (Kolden 2012) May overestimate fire severity because captures only immediate post-fire effects while disregarding resprouting or recovery of live vegetation. Ash cover, which decreases with time since fire, often increases reflectance values resulting in increased measures of high severity (Zhang 2025). Less definition in perimeter. Choice of assessment type matters for burn severity interpretation if using MTBS severity data
Extended Assessment Data acquired the first growing season after wildfire to quantify delayed mortality and primary regeneration (Kolden 2012) Forests (Kolden 2012) Includes vegetative recovery potential and delayed mortality (Key 2006) Better captures true fire effects in forest ecosystems where mortality is delayed; more appropriate for causal inference on biomass recovery
